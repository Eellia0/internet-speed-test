# Замер скорости скачивания

Консольный скрипт на Node.js без сторонних зависимостей.

## Запуск

Нужен Node.js версии 22 или новее. Откройте терминал в папке проекта:

~~~sh
node speed-test.mjs "https://example.com/large-image.jpg"
~~~

Замените пример на прямой HTTP/HTTPS-адрес доступного файла.
Установка через npm не требуется. Файл будет скачан 10 раз, учитывайте расход трафика.

## Как работает

Скрипт выполняет ровно 10 последовательных GET-запросов.
Следующий запрос начинается после полного чтения тела предыдущего ответа.
Ответ читается частями, файл на диск не сохраняется.
Перенаправления обрабатываются автоматически.

Для каждого запроса выводятся объём в байтах и время в миллисекундах.
Время измеряется от начала запроса до полного получения тела ответа,
включая ожидание сервера и установление соединения, если оно требуется.
Печать в консоль между запросами в измерение не входит.

Итоговые показатели:

- Среднее время запроса = сумма времени запросов / 10, в **мс**.
- Общий объём = сумма размеров прочитанных частей тела ответа, в **байтах**.
- Скорость = общий объём / суммарное время в секундах / 1 000 000, в **МБ/с**.
- **1 МБ = 1 000 000 байт**; МБ/с — мегабайты, а не мегабиты в секунду.

Скорость рассчитывается из общих объёма и времени, а не как среднее отдельных скоростей.
Заголовки HTTP и сетевые накладные расходы в объём не входят.
Скрипт просит сервер не сжимать ответ через Accept-Encoding: identity.
Если сервер всё же применит сжатие, fetch посчитает байты распакованного тела.

Это замер скачивания с выбранного сервера, а не гарантированная скорость интернет-тарифа.
Результат зависит от размера файла, задержек, сервера и повторного использования соединения.
Для более показательного результата используйте большой файл.

## Ошибки

Неверный адрес, сетевая ошибка, HTTP-статус вне 200–299 или превышение
60 секунд на один запрос приводят к сообщению об ошибке и коду завершения 1.
При ошибке замер прекращается: итог по неполным десяти запросам не выводится.

## Проверка

Внешние зависимости не нужны:

~~~sh
node --test speed-test.test.mjs
~~~

Интеграционные тесты запускают локальный HTTP-сервер и проверяют число
и последовательность запросов, полное чтение ответов, расчёты и ошибки.
